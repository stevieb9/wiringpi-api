- V11: auto_dispatch_interrupts (SIGIO) — ✅ 2026-06-05 attempt 1: PASS. - V14: Overflow policy + interrupt_buffer() sizing (promoted from B2) — ✅ 2026-06-05 attempt 1: PASS. Documented the contract in the interrupt_dropped() POD: edges FIFO-queue in the kernel pipe (non-blocking writes from the ISR thread); on a full pipe the newest are dropped — never merged, never blocked — and counted, so loss is never silent (debounce is the only intentional edge-collapsing mechanism). Added interrupt_buffer([$bytes]) (exported): getter returns the live pipe capacity (F_GETPIPE_SZ), or the pending request if not yet armed; setter validates a positive integer, requests it via F_SETPIPE_SZ and returns the kernel-granted size (page-rounded, capped at /proc/sys/fs/pipe-max-size). The request is remembered and applied when the pipe is (re)created, so it can be set before arming and persists across stop_interrupts re-arm (mirrors auto_dispatch_interrupts; tracked by $_interrupt_buffer_req/$_interrupt_buffer_fd). t/75 gains hardware-free get/set/validation coverage; make test 214 PASS. Hardware: set 1 MiB before arm → live size 1048576 after arm; persisted across stop+re-arm; live round-trip 128 KiB → 131072. Downstream: $pi->interrupt_buffer on RPi::WiringPi (process-wide → Pi object, NOT RPi::Pin) + a "Bursts and dropped edges" FAQ note; POD + Changes; hardware-verified. B2 slot retired.
